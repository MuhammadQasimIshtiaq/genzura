MUTUAL CRUSH "SPARK" (new)
- If A voted Secret Crush on B AND B voted Secret Crush on A, a small "Spark" pill shows on each other's profile (and in the Crush page). No notification, no push, no name sent anywhere.
- Publish the new firestore.rules (new collection: sparks). No new index, no new function. Android app: no change.
- How it works: the SECOND person to vote creates sparks/{lowUid_highUid}; the rules allow it only if both crushVotes docs exist with kind=crush. The first person sees the Spark next time he opens that profile / the Crush page. Votes themselves stay readable only by the voter.
- Legend votes never create a Spark. Both people must have Crush Vote turned ON and be friends/contacts.
