GUPZY CALLS - free, reliable TURN (Cloudflare Realtime TURN: first 1,000 GB / month free)
=========================================================================================
1) cloudflare.com -> sign up / log in (free) -> Dashboard -> Realtime -> TURN Server -> Create.
   Copy the "TURN Key ID" and the "API Token" (the token is shown only once).
2) Netlify -> your site -> Site configuration -> Environment variables -> add:
     CF_TURN_KEY_ID    = <TURN Key ID>
     CF_TURN_API_TOKEN = <API Token>
3) Put netlify/functions/turn.js from this zip into your repo (it REPLACES your old turn.js; keep a copy of the old one),
   deploy the site again.
4) Test: make a call between two phones on different networks (one on mobile data, one on Wi-Fi).
   The old expressturn server is no longer used.
Notes:
 - The app caches the credentials for 12 h. This build uses a new cache key (at_ice2), so everyone gets fresh credentials right away.
 - If the function is not configured the app falls back to the built-in servers (less reliable).
