GUPCHATS v3 - ONE inbox with Gupzy (like Facebook + Messenger)

What changed
- Gupchats now reads and writes the SAME chats as Gupzy (collection "chats", messages, photos, voice).
  A message sent in Gupchats shows up in Gupzy, and the other way round. The other person does NOT need Gupchats.
- Same encryption keys as Gupzy (userKeys) and the same message format. Verified with a test: Gupzy <-> Gupchats text,
  photos and voice open correctly in both directions.
- Same chat backup as Gupzy (keyBackups). ONE password works in both apps.
- Push: every chat message notifies the phone(s) of the receiver, whichever app sent it. If both apps are installed on
  one phone, the person gets a notification from each app.
- Calls: not yet (next step).

First time in Gupchats (once per phone / per account)
1) Gupzy -> Menu -> Chat backup -> create a password.
2) Open Gupchats -> sign in -> it asks for that same password (or tells you to make the backup first).
   Do NOT choose "start fresh" unless you forgot the password: it changes your key and Gupzy would need a restore.

What to publish
- worker/genzura-worker-all.js -> Cloudflare worker (push now also reaches Gupchats phones for every chat message)
- web files (gupchats/index.html)
- Firestore rules: no change needed. Old Gupchats-only chats (collection gcChats) are no longer used.
- Android: no change needed.

Not shown in Gupchats (open Gupzy for these): group chats, shared posts/reels, story replies, video sending.
