GUPCHATS v2 - push, photos + voice, stories + online dot, chat backup (multi-device)

WHAT TO PUBLISH (in this order)
1) firestore.rules            -> Firebase Console -> Firestore -> Rules -> paste -> Publish
                                 (new: gcPresence = online status, gcKeyBackups = private key backup)
2) worker/genzura-worker-all.js -> redeploy your Cloudflare worker (arain-api...workers.dev).
                                 New push kind "gcmessage" (Gupchats). Gupzy pushes are unchanged.
                                 (same change is in the worker only).
3) the web zip (gupchats/index.html) -> push to GitHub as usual
4) Gupchats Android: put google-services.json (package com.gupzy.chats) into app/ and rebuild (see its README)

HOW IT WORKS
- Push:   the phone saves its FCM token in fcmTokens with app:"gc". The worker sends a Gupchats push only to tokens with
          app:"gc", and never sends Gupzy pushes to them. Text is generic (end-to-end encrypted).
- Photos / voice: encrypted on the phone with a random key, uploaded as a "raw" file to your Cloudinary (same cloud + preset as Gupzy).
          The key travels inside the encrypted message. Cloudinary only ever holds unreadable bytes.
          IMPORTANT: your upload preset must accept RAW uploads. If sending a photo says "Upload failed", open Cloudinary ->
          Settings -> Upload -> preset "arain_unsigned" and allow all formats / raw files.
- Stories: same "stories" collection as Gupzy. Friends = people who follow each other. Photo and video stories (max 30 s, 60 MB) can be created in Gupchats,
          Gupzy videos play in Gupchats too. 24h expiry, view counter for your own stories.
- Online dot: each phone writes gcPresence/{uid} every 60 s while the app is open (and "offline" when it goes to the background).
          Settings -> "Show when I'm online" off = you are hidden and you also do not see others.
- Multi-device: the private key can be backed up, encrypted with a backup password (PBKDF2 310k + AES-GCM) in gcKeyBackups/{uid}.
          New phone / reinstall: sign in -> enter the password -> old messages readable again.
          Forgot the password = start fresh (old messages unreadable). Nobody, including you as admin, can recover it.
- Older installs: keys created before this version cannot be backed up. Settings -> Chat backup -> Turn on asks to create a new key
          (old history becomes unreadable) - that is a one-time step.

KNOWN LIMITS
- If a FRIEND reinstalls without a backup, their new key makes your old messages with them unreadable on both sides.
- Stories list reads the 300 newest unexpired stories (same as Gupzy), so on a very busy app some friends' stories can be missed.
- Story videos: max 30 s and 60 MB, uploaded as-is (no re-compression), so shorter clips upload faster.
