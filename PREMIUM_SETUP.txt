GUPZY PREMIUM ($3 / month) - setup notes
=========================================
Data used (Firestore):
  channels/{uid}.premiumUntil   number (ms). Premium is active while it is in the future.
  channels/{uid}.pm             { border, badge, theme, chatTheme, icon }  (user's own choices)
  premiumRequests/{uid}         payment request (same idea as verifyRequests)
  settings/premium              optional payment details (falls back to settings/blueTick)

FIRESTORE RULES - IMPORTANT (otherwise anyone could give themselves Premium):
  1) channels/{uid}: the owner may update everything EXCEPT premiumUntil. Only admin may write premiumUntil.
     Example inside your existing channels update rule:
       && !request.resource.data.diff(resource.data).affectedKeys().hasAny(['premiumUntil'])
     (admin UID may write anything, as for referredByAdmin today)
  2) premiumRequests/{uid}: copy the rules of verifyRequests
     (owner create/update own doc with status 'pending', admin read/update all).
  3) settings/premium: read for signed-in users, write only admin (same as settings/blueTick).

How it works:
  User -> Menu -> "Gupzy Premium" -> pays via JazzCash/EasyPaisa/Bank/Payoneer -> submits txn ID.
  Admin -> Admin Panel -> "Premium" tab -> Approve (days shown on each request) / Reject, or give days by channel ID.
  Renewal adds 30 days on top of the remaining time. When premiumUntil passes, everything
  (border, crown, themes) switches off automatically.
